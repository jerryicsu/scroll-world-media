# scroll-world media

Large media assets for [scroll-world](https://scroll-world-bjm.pages.dev), served over
GitHub Pages because they exceed Cloudflare Pages' 25 MiB per-file limit.

| File | Size | Used by |
|---|---|---|
| `CutB_scroll_720p_web.mp4` | 38.8 MiB | [One Box, One Journey — scroll version](https://scroll-world-bjm.pages.dev/one-box-one-journey/scroll/) |

720p, CRF 27, a keyframe every 4 frames so the page can seek within 0.17 s while
scroll position drives `currentTime`.

Imagery is AI-generated and depicts a generic container terminal; no real facility,
vessel, operator or shipping line is represented.
